# Portal Dashboard

The kitchen dashboard running on Sameer's 2nd-gen Meta Portal (WD50JM):
a local web page (clock/weather, prayer, groceries, calendar, photos, word
of the day) served and backed by **DashServer**, a small Android app on the
device. Project record and design decisions live in the companion repo
`portal-muse-plan` (LOG.md).

## Layout

- `index.html` — the dashboard page (single file; served by DashServer on
  port 8321 and also opened full-screen by its Dashboard activity)
- `build_data.py` — builds `data.json` (weather, prayer, grocery snapshot,
  agenda, `calweeks`) on the host side
- `push_snapshot.py` — pushes the snapshot + page to the Portal (no-op
  until `portal-push.json` exists)
- `daily_word.py` — word-of-the-day feeds (Transparent Language RSS)
- `dashserver/` — DashServer Android source (raw toolchain build, no Gradle)

## Show page (visual answers)

- `show_on_portal.py` posts visual content to DashServer's `/api/show`;
  DashServer stores it in `show.json` in the served directory, and the
  dashboard page polls `/api/show` every 5 seconds to render it.
- **Caller rule (2026-10-27):** for a visual Portal ask (recipes,
  how-tos, lists, comparisons), post the full content to the Show page
  as soon as it's ready and keep the spoken reply to one brief
  confirmation. Do not read the card's sections or details aloud
  unless Sameer asks. Recipe/how-to cards also carry the video (or
  source) link and its thumbnail — the Open button needs a URL, and a
  YouTube link opens in SmartTube.

## Deploy routes

- **Page:** PUT to the Portal's DashServer upload endpoint from the Mac —
  `PUT http://192.168.1.117:8321/upload/index.html` with the `.dash-token`
  bearer (token lives only in the local `.dash-token` file, never in git).
  Always use absolute paths in `curl --data-binary @…` and md5-verify the
  served file afterwards.
- **DashServer:** built on the Mac (`~/dashbuild/build.sh`: javac → D8 →
  aapt2 → zipalign → sign, same cert every build) and installed with
  `adb install -r`.
- **Data:** `data.json` is generated by `build_data.py` and is **not** in
  git — it carries live household data.

## Secrets

`.dash-token`, the service-account key (`sa-key.json`, which lives only in
the app's private storage on the device), and all generated data files are
gitignored and must never be committed.
